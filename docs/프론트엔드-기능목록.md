# F1 25 레이스 엔지니어 · 프론트엔드 기능 목록

Windows용 PySide6 앱을 1920×1080 서브모니터에서 사용함. 첫 산출물은 게임을 꺼둬도 조작할 수 있는 A/B 두 탭임. 샘플 레이스가 양쪽에 같은 경기 상태와 미리 준비한 분석 결과를 공급함.

## A탭 · 라이브 타이밍

[A탭 화면 시안](A-live-timing.png)

- [x] **전체 순위표** — 순위, 드라이버, GAP(선두와의 차이), INT(바로 앞 순위와의 차이), 최근 랩, S1·S2·S3, 타이어 종류와 사용 랩을 표시함. 참가 차량 수에 맞춰 행을 구성함.
- [x] **실시간 서킷맵** — 차량 위치를 움직이고 내 차와 순위상 앞·뒤차에 라벨을 붙임. 순위가 바뀌면 표와 맵이 같은 차량을 가리켜야 함.
- [x] **경기 상태와 이벤트** — 서킷, 세션, 현재 랩/총 랩, 플래그를 표시함. 피트 진입·복귀, 개인 최고 랩, SC/VSC 등 최근 사건을 랩 번호와 함께 보여줌.

## B탭 · 내 레이스

[B탭 화면 시안](B-my-race.png)

- [x] **주변 순위표** — 순위상 내 앞 2대, 나, 뒤 2대를 표시함. 내가 P8이면 P6~P10, P1이면 P1~P3이 보임. 각 행은 순위, 드라이버, GAP, INT, 최근 랩으로 구성함. GAP와 INT의 기준은 A탭과 같음.
- [x] **내 순위와 앞뒤 간격** — 고정된 위치에 내 순위, 앞차 이름·간격, 뒤차 이름·간격을 크게 표시함.
- [x] **추격·방어 분석** — 앞차와 뒤차 각각의 랩당 페이스 차이, 격차가 줄어드는지, 현 페이스에서 몇 랩 뒤 1초 이내가 될지를 표시함. 표본이 부족하거나 앞차가 피트에 들어가면 이전 예측을 지움.
- [x] **타이어와 페이스** — 현재 컴파운드, 사용 랩, 최근 정상 랩의 페이스 추세를 표시함. SC 구간이나 피트 랩이 섞이면 해당 상태를 표시함.
- [x] **피트 전략 비교** — 현재 계획의 피트 랩·다음 타이어를 고정해 두고, ‘지금 피트’와 ‘한 랩 더’의 예상 복귀 순위·주변 차량을 비교함. 예상값에는 ‘예상’을 붙임.
- [x] **앱 안에서 전략 선택** — 후보 이동은 미리보기, 확정은 현재 계획 변경, 취소는 기존 계획 유지로 동작함. 직접 설정에서는 피트 랩과 다음 타이어를 바꿀 수 있음. 출발 전에는 같은 B탭에서 출발 타이어와 스틴트별 교체 계획을 편집함.

## 휠 조작과 표시 규칙

- [x] **앱솔루트 다이얼** — 위치별 버튼을 A탭 또는 B탭에 직접 할당함. 같은 위치 신호가 반복돼도 탭이 다시 열리거나 전략이 확정되지 않게 함.
- [x] **휠 스틱** — 후보 이동, 값 변경, 확정, 취소를 실제 버튼에 매핑하고 다음 실행 때 복원함. 개발 중에는 키보드로도 같은 조작을 시험할 수 있게 함.
- [x] **가독성** — 검정·짙은 회색 바탕, 붉은 헤더, 고정 폭 숫자, 팀 컬러 표시를 사용함. 타이어는 색과 문자로 함께 구분함. 탭을 바꿔도 현재 랩과 확정한 계획이 이어짐.
- [x] **데모와 데이터 상태** — 샘플 재생 중에는 ‘데모’를 표시함. 값이 없을 때는 ‘—’, 데이터가 부족해 예측할 수 없으면 ‘분석 대기’로 표시함.

## 구현 순서와 완료 조건

1. 공통 헤더·탭·샘플 경기 상태를 연결하고 A탭의 전체 표와 맵부터 완성함.
2. 같은 상태에서 B탭의 주변 5대와 분석 결과를 표시하고 전략 미리보기·확정·취소를 연결함.
3. 다이얼·스틱 매핑을 붙이고 다음 장면을 반복 재생해 확인함.

| 샘플 장면 | 통과 기준 |
|---|---|
| P8에서 P7로 추월 | A탭 순위표·맵의 강조와 B탭 주변 표가 함께 바뀜. 내 차 강조가 같은 드라이버를 따라감. |
| 앞차 추격 중 상대 페이스 회복 | ‘4랩 뒤 1초 이내’에서 ‘격차 벌어지는 중’으로 바뀜. 앞차가 교체되면 이전 차량의 예측이 사라짐. |
| 21랩 하드 전략에서 19랩 후보 선택 | 후보를 보기만 하면 현재 계획은 21랩임. 취소하면 21랩, 확정하면 19랩이 표시됨. |
| SC 발령 또는 데이터 부족 | 플래그와 이벤트가 갱신되고 유효하지 않은 피트·추격 예측은 대기 상태로 전환됨. |
| 운전석에서 휠로 조작 | 1080p 전체 화면에서 샘플 22대가 보이고, 마우스 없이 A/B 전환과 전략 확정·취소까지 가능함. |

이 체크를 통과하면 샘플 분석값을 Rust가 계산한 값으로 교체하고 PyO3로 연결함. 그 뒤 읽기 전용 UDP를 붙임. 인게임 팀라디오, 피트 호출, 타이어 선택 전송은 후속 연동 단계임.

## 검증 기록

- [x] Windows 기본 렌더러에서 1920×1080 양쪽 탭 캡처. A탭 22행, B탭 주변 5행 표시 확인.
- [x] 자동 테스트 6개 통과: 순위·분석 전이, 전략 미리보기·확정·취소, 출발 전 다중 스틴트, 휠 매핑 저장·복원, 1080p 배치, SDL 가상 휠(56번 버튼·POV) 입력.
- [ ] 실물 휠에서 다이얼과 스틱 바인딩 후 운전석에서 확인. 구현 시점에는 연결된 실물 휠 없음.
